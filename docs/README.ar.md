# Glassio

Glassio هو مشغّل خفيف لأجهزة Android TV، بواجهة سينمائية وشريط تطبيقات وإعدادات زجاجية وخلفيات مخصصة وشاشة توقف ومكتبة محلية ودعم Trakt.

## المزايا

- التنقل باستخدام جهاز التحكم عن بُعد.
- تخصيص واجهة العرض والصور والانتقالات وتبديل الخلفيات تلقائياً.
- سمات زجاجية وشفافة وداكنة، مع إعدادات منفصلة للشريط ولوحة الإعدادات.
- تطبيقات ومجلدات وأيقونات مخصصة.
- مكتبة محلية ودعم اختياري لقائمة المشاهدة في Trakt.
- خلفيات صور وفيديو وخيارات شاشة توقف.
- واجهة بالإنجليزية والتركية من الإعدادات ← اللغة.
- أوضاع أداء للأجهزة ذات الذاكرة المحدودة.

## البناء

يتطلب Android SDK وJDK 17 أو إصداراً متوافقاً واتصالاً بالإنترنت لتنزيل Gradle والاعتماديات.

```bash
./gradlew assembleDebug
```

يوجد ملف APK الناتج في `app/build/outputs/apk/debug/app-debug.apk`.
