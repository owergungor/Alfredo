# Clock glass implementation note

The large clock's visual approach is inspired by Seagey's [Couch-TV](https://github.com/Seagey/couch-tv), which is released under the MIT License. This Glassio implementation uses its own Jetpack Compose drawing code and samples Glassio's existing blurred wallpaper bitmap inside the clock glyphs, with a translucent highlight and fine rim. No Couch-TV source file is copied into this project.

Couch-TV repository license: MIT. See https://github.com/Seagey/couch-tv/blob/main/LICENSE.
